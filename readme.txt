SECTION 1. Contents of CD
------------------------------

This CD contains the following:

A. "InstallInteractivePhysics.exe"

SECTION 3. Installation and Use Instructions
--------------------------------------------

Installing Interactive Physics:
(If the full edition of Interactive Physics 5.0 or higher is already 
installed on your computer, go directly to the section
"Installing and running Interactive Physics Workbook Simulations" below.)

1. Insert the CD into the CD-ROM drive
2. Double-click on My Computer and then double-click on the CD-ROM drive
3. Double-click on InstallInteractivePhysics.exe to install
4. Follow the instructions as prompted
5. Restart computer if prompted


Checking/Updating display settings:

1. Go to Display in the control panel to change settings
2. Click the tab labeled "Settings"
3. Set the monitor color to 256 colors or higher (16-bit high color recommended)
4. Set the Display area to 800 x 600 or higher


Using Interactive Physics:

1. Double-click on the icon "Interactive Physics" on your desktop to run the program.


Running Interactive Physics Workbook Simulations:

1. Browse to root directory of the CD or the directory where 
   Interactive Physics was installed, for example, "c:\Program Files\IPWorkbook".
2. Then browse to the subfolder "Simulations"
3. Double-click on any of the files to open the simulation.


Printing Simulations:
1. Have Interactive Physics as the active window 
2. To copy the contents of the active window to the computer clipboard, 
   simultaneously press Alt-PrintScreen
3. Open a program such as Microsoft Word or Paint 
4. Under the Edit menu in the new program (e.g. Microsoft Word), choose Paste 
5. Under the File menu in the new program (e.g. Microsoft Word), choose Print 


Un-installing Interactive Physics:

1. Under Start menu, click on Settings, then Control Panel, then Add/Remove Programs
2. Select Interactive Physics and click Change/Remove
3. Click "Yes" to continue with un-installation process.
